# Użycie narzędzi AI

W pracach nad backendem części B użyto OpenAI Codex jako asystenta programistycznego.
Pomagał czytać dokumentację, porównywać źródła, wdrażać funkcje, pisać testy i redagować
dokumentację. Zakres zmian i wybory metodyczne opisują historia Git oraz metodyka.
Narzędzie jest usługą OpenAI używaną zgodnie z warunkami właściwymi dla konta.
[Warunki OpenAI](https://openai.com/policies/terms-of-use/), [metodyka Vedry](METHODOLOGY.md).

W działającej aplikacji kod oblicza wskaźniki z danych oraz dobiera tekst i uzasadnienia
według reguł. Opisy zaleceń pochodzą z wersjonowanego słownika, a raport zawiera przesłanki
i odsyłacze do źródeł. Aplikacja działa bez połączenia z usługą generatywnej AI.

Przy weryfikacji części B sprawdzono cytowane progi względem rozporządzenia, uruchomiono
testy obliczeń i API oraz porównano identyfikatory przypadków historycznych z załącznikami
MRiRW. Zakres przeprowadzonego porównania podano osobno.
[Walidacja KBW](VALIDATION.md).
